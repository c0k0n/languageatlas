# Contributing to Language Atlas

Language Atlas is a small reference project, not a ranking of languages. Corrections and thoughtful improvements are welcome.

## Data changes

Please explain the source for a classification change. Some categories are fuzzy by nature, so describe the reasoning instead of treating every label as absolute.

## Code changes

The project is intentionally dependency-free. Keep it that way unless there is a strong reason to change it. Preserve the offline behavior, keyboard access, responsive layout, and shareable filter URLs.

Because the page loads `data.json`, serve the project over HTTP when testing locally. Please include what you checked in the pull request description.
